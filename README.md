## Create Fly Backport
A community backport of Create Fly to Minecraft 1.21.1, bringing its Fabric-based Create experience to a version not supported by the original project, which is currently available for Minecraft 1.21.8 and newer.

### Stability & Support

The current version is considered stable, but bugs, crashes, and compatibility issues may still occur. Issues may be reported on GitHub, although fixes may take considerable time or may not be implemented, as this project is not maintained full-time.

Do not use with Flywheel Compat or Colorwheel as it's already embedded on the mod.
